# bili-danmaku-blocklist-importer

B 站弹幕屏蔽词一键导入工具：油猴脚本 + 一套以「误伤最小」为原则整理的屏蔽词库。

官方的弹幕屏蔽只能一条条手敲，手机 App 不支持文件导入，第三方词包网站依赖站点在线。本脚本在 bilibili.com 页面内注入一个小面板，把词条批量写入**账号云端**的弹幕屏蔽列表（官方弹幕过滤体系，全端生效）。

## 功能

- **按分类导入**：内置词库拆成 10 个分类（见下表），面板里勾选想要的分类一键导入，前 4 个高置信分类默认勾选
- 三种导入来源：勾选分类 / 粘贴词条文本 / 选择本地 `.txt` `.xml` 文件（兼容 B 站播放器导出的 XML，其中 `enabled="false"` 的词条自动跳过）
- 词条格式：每行一条；`r=` 开头为正则；`#` 开头为注释
- 安全导入：先拉取云端已有列表去重，350ms/条 限速，失败后重跑可续传，实时进度日志
- 导出备份：一键把账号当前屏蔽列表（含正则）下载为 txt

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 从 Greasy Fork 安装（推荐，可自动更新）：*发布后填写*
   或手动安装：打开 [bilibili-blocklist-importer.user.js](bilibili-blocklist-importer.user.js)，全选复制 → Tampermonkey 面板 → 添加新脚本 → 粘贴保存
3. 打开任意 bilibili.com 页面（需已登录），点击右下角「屏蔽词」角标或油猴菜单中的「屏蔽词导入面板」

## 使用

| 按钮 | 作用 |
| --- | --- |
| 导入勾选分类 | 把勾选的分类词条批量写入账号云端 |
| 导入以上自定义内容 | 导入文本框里粘贴的词条（或所选文件内容） |
| 选文件 | 导入本地 txt / xml 屏蔽词文件 |
| 导出备份 | 把账号当前屏蔽列表下载为 txt |

## 词库说明

以**误伤最小**为原则整理，见 [blocklist.txt](blocklist.txt)：前四组（广告引流、引战对喷、低质刷屏、结构化正则）是高置信的，建议直接导入；高频梗、时政引战、烂梗三组误伤风险高或属口味取舍，txt 里以注释形式提供、XML 里以关闭状态导入，需要时再启用。单字屏蔽（美/丑/急）这类极端误伤词始终不收录。

## 声明

- 本项目与 B 站官方无关；调用的是 `api.bilibili.com` 的非官方公开接口
- 脚本只在 bilibili.com 页面内运行；登录凭据（CSRF token）仅用于本机向 B 站发请求，不发送给任何第三方
- 批量添加存在触发接口限流的可能，脚本已做限速与去重防护，使用风险自负

## 已知限制

- 不支持「屏蔽用户（UID）」类型，仅支持关键词与正则
